# Fontes queimadas

Estas fontes não são ruins. Ficaram tão comuns em interface gerada por IA, ou entre as mais usadas do Google Fonts, que hoje fazem qualquer tela parecer igual às outras.

Só entram se a pessoa pedir pelo nome, ou se já forem a fonte do projeto ou da marca.

## As padrão de sempre

Inter, Roboto, Open Sans, Lato, Arial, Helvetica, `system-ui` usado como escolha de marca, Montserrat, Poppins, Raleway, Nunito, Nunito Sans, Mulish, Work Sans, Source Sans 3, Fira Sans, Ubuntu, PT Sans, Noto Sans, Arimo, Kanit, Prompt, Rubik, Quicksand.

## As "modernas" que viraram padrão

DM Sans, Plus Jakarta Sans, Manrope, Outfit, Figtree, Jost, Barlow, Red Hat Display, Bricolage Grotesque, Instrument Sans, Space Grotesk, Geist, Exo 2.

## As de título que viraram vício

Playfair Display, DM Serif Display, Instrument Serif, Fraunces, Lora, Merriweather, Roboto Slab, Oswald, Roboto Condensed, Barlow Condensed, Bebas Neue, Archivo Black, Orbitron, Black Ops One, Dancing Script.

## As mono de sempre

JetBrains Mono, Roboto Mono, Source Code Pro, Inconsolata, Space Mono, Geist Mono.

## Como identificar uma nova

Uma fonte deve entrar nesta lista quando:

- ela aparece em várias interfaces geradas sem que ninguém tenha pedido;
- ela é a primeira que vem à cabeça para "sair do Inter";
- ela está entre as ~35 mais usadas do Google Fonts.
